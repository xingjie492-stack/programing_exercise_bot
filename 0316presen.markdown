# プログラミングお題出してくれるくん
## 開発のきっかけ
<ul>
    <li>自分はこの訓練校ではじめて本格的にプログラミングに触れた。</li>
    <dd><li>その結果、プログラミングは結構面白いと感じた。</dd></li>
    <li>一方、世に自分のアプリケーションを問うてみたい、といったようなアイデアや野心はない。</li>
    <dd><li>なんでもいいから書いて練習したい、その辺からお題が生えてきたらいいのに。</dd></li>
</ul>

## こんなアプリ作りました
* アプリの画面キャプチャやイメージ画像
* 「ユーザが選択した言語・難易度に応じた問題生成」
* 「講評、模範解答表示機能」
* 「履歴機能で、過去に生成した問題に再挑戦も可能」

## 開発環境
* フロント：HTML/CSS、Javascript
* 言語：python
* フレームワーク：Flask
* DB：SQLite
* 生成AIモデル：gemini-2.5-flash-lite
* バージョン管理：git/github

## 機能①：CRUD機能を持つアカウント管理
<ul>
    <li>新規登録・ログイン・ログアウト・会員情報変更・削除が可能なアカウント管理機能。</li>
    <li>管理者アカウントでログインすると、DB上の他の会員情報にアプリケーションからアクセスできる。</li>
    <dd><li>変更を加えたり、削除も可能。</li></dd>
</ul>

## 機能②：お題生成機能
<ul>
    <li>プルダウンメニューで選択した言語と難易度に応じたお題を生成する機能</li>
    <dd><li>Geminiに「お題をくれ！」というプロンプトを投げ、お題が返ってくるという流れ。</dd></li>
    <li>投げるプロンプトはユーザの選択に応じてif文で判定して選ぶという処理を行っている。</li>
    <dd><li>Geminiの温度は0.7と高めに設定している。お題を出すという機能の性質上、毎回異なった生成結果を得る必要があるため。</dd></li>
</ul>

## 機能③：講評機能
<ul>
    <li>フォームに回答となるコードを張り付けると、それをGeminiが100点満点で講評してくれる。</li>
    <dd><li>ちょっとした解説も付してくれる。プロンプトにて講師の役割を与えたため。</dd></li>
    <dd><li>Geminiの温度は0。生成結果に一貫性が求められるため。</dd></li>
</ul>

## 機能④：模範解答機能
<ul>
    <li>現在表示している問題の模範解答を表示する機能。</li>
    <dd><li>こちらも講師としてちょこっと解説してくれる。</dd></li>
    <dd><li>講評と同様の理由で温度は0</dd></li>
</ul>

## 機能⑤：お題履歴機能
* 生成したお題はDBに保存され、履歴を閲覧することができる。
* 再挑戦も可能。解けなかった問題にリベンジしたり、できた問題でも別解を考えたりできる。
* 削除並びに一括削除も可能で、履歴が溜まるのが気持ち悪いという方にも安心。

## 工夫した点
* お題生成と講評・模範解答とでGeminiの温度を変えるようにした。
* 開発中に、実装した機能が動作するかを確認するにあたって、いちいちGeminiにプロンプトを投げてしまわないように設定した。
* 開発の後半では、pytestを活用したテストを実施した。

## 開発で苦労した点
<ul>
    <li>難易度選択機能</li>
    <dd><li>どこまで”かんたん”で、どこから”むずい”のか？それを選んでプロンプトを投げるにはどうしたらよいか？と悩んだ。</dd></li>
    <dd><li>難易度の区分は各言語の資格試験に従って設定し、投げるプロンプトの選択にはif文を使った。</dd></li>
    <li>フロントのJavaScript</li>
    <dd><li>お題、講評、模範解答の表示に必要だったので、Geminiに生成してもらったコードを利用。</dd></li>
    <dd><li>自分なりにJavaScriptのところで何をしてるのかを理解するよう努めたが、そもそも知識が足りない。</dd></li>
</ul>
