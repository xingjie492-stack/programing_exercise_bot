# Programming Exercise Bot  
### プログラミング学習支援Webアプリ

---

## 1. 背景

- プログラミング学習では
  - 問題を探すのが面倒
  - 自分のコードの良し悪しが分かりにくい
- 継続的な練習とフィードバックが重要

---

## 2. 目的

- 問題生成からレビューまでを自動化
- 学習効率の向上
- 初学者でも継続しやすい環境を提供

---

## 3. システム概要

このアプリは以下を一括で提供：

1. 問題生成  
2. コード提出  
3. AIレビュー  
4. 履歴保存  

---

## 4. 主な機能

### 問題生成
- 難易度指定可能
- 言語指定可能

### 回答提出
- Web上でコード入力

### AIレビュー
- コードの改善点提示
- 解説付きフィードバック

### 参考解答
- 模範的なコードを提示

### 履歴管理
- 過去の問題・回答を保存
- 振り返りが可能

---

## 5. 技術スタック

- Backend: Flask
- Database: SQLite（SQLAlchemy）
- Migration: Flask-Migrate
- Auth: Flask-Login
- AI: Google Generative AI / LangChain

---

## 6. システム構成

- フロントエンド：ブラウザ
- バックエンド：Flask
- データベース：SQLite
- 外部サービス：AI API

---

## 7. データ構造（簡略）

### User
- ユーザ名
- メール
- パスワード

### Submission
- 問題文
- 回答コード
- レビュー
- 参考解答

---

## 8. デモフロー

1. ログイン  
2. 問題生成  
3. コード入力  
4. レビュー確認  
5. 履歴に保存  

---

## 9. 工夫した点

- 機能ごとにビューを分離（可読性向上）
- 認証機能を実装（ユーザ単位で管理）
- AIレビューと履歴を連携

---

## 10. 課題

- UIがシンプルすぎる
- AIの回答品質にばらつき
- エラーハンドリング不足

---

## 11. 今後の展望

- UI/UX改善
- 問題の難易度精度向上
- Docker化
- チーム機能追加

---

## 12. まとめ

- 学習の「問題 → 実装 → 振り返り」を一体化
- AIを活用した効率的な学習支援ツール
- 初学者から中級者まで活用可能
